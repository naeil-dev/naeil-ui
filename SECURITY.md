# Security reporting

This project is maintained by the naeil-dev organization at https://github.com/naeil-dev/naeil-ui. There is no published supported-version matrix or guaranteed response deadline.

GitHub private vulnerability reporting was **disabled when checked on 2026-10-02**. A private report form is not currently a confirmed reporting channel. For a sensitive issue, open a minimal [GitHub issue](https://github.com/naeil-dev/naeil-ui/issues/new) requesting a confidential contact method; do not include exploit details, credentials, personal data, or a working attack. Wait for a maintainer to provide a private channel before sending the details. If maintainers later enable private vulnerability reporting, use GitHub's private report flow then.

For non-sensitive bugs use the normal issue template. Include the affected version/import, environment, minimal reproduction, and impact when it is safe to disclose. Never post live keys or session cookies. Do not test against production services or other people's accounts without authorization.
