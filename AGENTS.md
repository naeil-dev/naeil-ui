- Page rhythm / service shell (0.15.0): owned services use `NaeilServiceShell` + root `NaeilThemeProvider` from `/naeil-shell` (standalone) or `/naeil-locale/chrome` (provider-backed), start pages with `PageHeader`, and run `naeil-ui-conformance --service <id> --framework next|vite --app <dir>` and runtime `naeil-ui-conformance --service <id> --url <origin> --routes /a,/b [--no-footer /login]` in CI (consumer-installed Playwright). Do not rebuild frame/theme/base text/favicon policy, style reserved chrome selectors or add page padding/title sizes. Use server-safe `naeilIcons` and title helpers from `/naeil-locale`. Record any `footer={false}` screen or CLI ignore reason. See `docs/components/naeil-shell.md` and DESIGN.md "Page rhythm".

Shared navigation/footer have built-in frames; do not wrap them in another padded frame. Keep reading/settings at 640px and short forms at 480px inside main. Change numeric values in `src/tokens/ui.json`; preserve supported generic/legacy overrides without applying them to the protected shell.
