Anonymous production comparisons did not exercise this state.

Real name/email may appear inside the menu; the trigger does not invent or depend on a shared identity. Signed-out state uses the same login link with the app's route adapter. Jev retains locale and full-document logout navigation. Site retains its localized session action. Busy state disables logout while keeping the menu trigger available for focus and inspection. A rejected/cancelled consumer action must leave a usable trigger. Language focus outlines remain visible and are compared under matching focus conditions.
