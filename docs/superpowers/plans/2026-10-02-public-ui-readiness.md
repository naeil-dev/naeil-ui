## Structure and compatibility decisions

- Keep one package/source layout. `/ui` is the React core; `/utils` and CSS contracts remain. The legacy root is a framework compatibility barrel with static Next/next-intl imports. Those are optional peers required by root/Nav/Footer/i18n use; next-themes remains a React runtime dependency for existing theme/Toaster behavior.
- Eight runtime dependencies, website tooling development-only. Exact shared deep entries replace wildcard compilation; preserve observed Nav/Footer/theme/locale imports and document excluded website paths. The internal inert helper ships for relative deep resolution without a public export. No hero/cursor/Supabase/login/MDX/Three/messages in UI payload.

A reachable consumer pins 0.1.0 and scans old src paths; preserve actual imports and explain migration to compiled dist/shared CSS. Copied UI demand is distinguished from installed-package adoption. No consumer projects are modified.

A document-owned shared registry preserves original inert values across nested/overlapping and mixed bundled/deep entries, refs/handlers, unmount and StrictMode. Modal defaults and public exports are preserved.
- Static documentation excludes website assets through both Storybook staticDirs and Vite publicDir. Actual preview and conservative manager dependency inventories retain original full notices, including Lucide's mixed notice; upstream missing-version/metadata limitations are explicit. Unknown brand-art rights and fetched site-font notices remain outside the shared artifact claim.

## Demand decision

Root verified the private scoped provenance inventory and directly inspected route imports/render chains. Four reached local/copied-Radix Tabs compositions span three distinct products, excluding worktrees/snapshots/wrapper-only definitions. One of those products separately installs @naeil/ui 0.1.0; its Tabs use is still local, not an existing package API.

Textarea repeats in one copied-UI product's routed brief/description/composer/correction flows. Another native file editor corroborates multiline demand without establishing a second styled adopter or editor contract. Adopt native props/ref, rows=2 and vertical resize defaults; no autosize, send-on-Enter, IME/file/editor logic. Tabs forwards Radix props/ref/classes with horizontal/automatic/no-forceMount defaults; no route/session or unused variant system.

FormField remains label/id/help/error/describedby composition. No existing RadioGroup/native-radio use was observed, but one routed product has candidate exclusive single-choice buttons. Guide native fieldset/legend + same-name radios, compact Select and action/toggle distinctions; defer a shared RadioGroup wrapper for lack of a broader common styled contract, not absence of need. Structural inspection is not live consumer-quality verification.
