# Shared UI v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the selected neutral foundation and reusable components inside the existing package, with working Storybook compositions and package-level verification.
**Architecture:** JSON tokens generate the CSS that the package exports. Existing React/Radix components consume semantic roles and root density variables; Select, Switch, and Checkbox use Radix behavior. Product data lives only in examples.
**Tech Stack:** React 19, Tailwind 4, Radix, Style Dictionary 4, Storybook 10, Vitest, Playwright.
**Spec:** `docs/superpowers/specs/2026-09-29-shared-ui-v2-design.md`

## Global Constraints

- Neutral actions; Pretendard; body/control 16px; supporting 14px; metadata 13px.
- Reading/settings maximum 640px, lists 1,200px; short forms 480px and fluid data layouts are explicit exceptions.
- Default controls 40px / rows at least 72px; compact 36px / 60px; small-screen targets at least 44px.
- Radius 4/8/12px; transitions 120/180ms; OS reduced motion wins.
- Preserve existing public exports and variant props. No site redesign, new motion library, package publishing, or deployment.
- Root density uses `data-ui-density`; explicit light/dark wins over OS theme.

## Review Focus

- Missing/invalid contrast values must fail rather than silently report success (Task 1).
- Theme/density must also reach portaled Select and Dialog content (Tasks 2–4).
- Disabled controls, labels, keyboard selection and focus restoration must work in a real browser (Tasks 3–4).
- Long multilingual text and 390px viewports must reflow without global overflow (Task 4).
- Packed exports and CSS must survive clean builds and work outside this checkout (Task 5).
