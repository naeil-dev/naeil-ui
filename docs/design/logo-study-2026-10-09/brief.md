# naeil 로고 검토 — 2026-10-09

후속 피드백: 사용자는 아래 영문 n/ae 중심 시안보다 기존 ㄴ과 해의 의미, 따뜻함과 새출발을 우선한다. 다음 탐색의 기준은 [의미 중심 방향 기록](meaning-exploration/direction.md)이다. 아래 내용은 첫 번째 형태 비교의 기록이다.

사용자 요청: 조사한 로고 제작 방식을 재사용할 아이콘/로고 스킬로 만들고, 그 절차를 naeil에 적용한다. naeil은 한국어 ‘내일’이며 원하는 인상은 **차분하지만 독특한 제품 브랜드**다.

## 작업 계약

- 범위: 공통 스킬 설치와 비교용 로고 3안. 기존 로고·Nav·Footer·로그인 화면을 직접 교체하는 단계는 아니다.
- 기준: DESIGN.md의 중립 색상과 차분한 인상. 검토 화면은 Pretendard 우선, 시스템 글꼴 대체. 실제 로고 글자는 외부 글꼴에 의존하지 않는 원본 SVG 경로.
- 사용처 가정: 새 웹 헤더 로고 32px 높이, 독립 심벌 24/32/64px, 파비콘 16px. 기존 Nav/Footer가 쓰는 심벌 20px도 추가 확인한다. 특정 모바일 플랫폼 앱 아이콘 규격은 이번 범위에 없다.
- 재사용: 현재 로고는 src/components/logo.tsx에서 비교용으로 재현한다. 새 SVG와 검토 화면은 공유 패키지 컴포넌트·API·토큰을 바꾸지 않는 원본 제작물이다.
- 해결할 빈 부분: 기존 ㄴ/L + 반원은 의미는 설명하기 쉽지만 개성을 더하기 어렵다는 사용자 판단. ‘내일’ 의미는 출발점으로 삼되, 해·일출·전진 화살표의 반복을 피하고 이름/여백/글자의 형태를 비교한다.
- 검증: 실제 SVG 렌더, 16/24/32/64px, 큰 형태, 밝은/어두운 배경과 단색, 헤더 배치. 작은 래스터 확대와 경로/참조 검사. 사람의 기억·선호·상표 유사성은 별도 판단 대상이다.
- 이월: 기존 프로젝트의 접근성·배포·라이선스 감사 결과는 이 로고 시안 작업으로 해소되지 않는다. 새 시안의 사용처 선택과 제품 반영도 별도 결정이다.

적용 스킬: $logo-icon-design, /Users/jaymini/.codex-pooled/skills/logo-icon-design/SKILL.md. 스킬은 이 프로젝트의 전용 스타일을 강제하지 않는다.

워드마크는 원본 경로로 그린 소문자 naeil이며, 앞의 점을 생략한 표기도 함께 검토한다. 이번 시안에서 선택한 표기이지 기존 제품의 이름 표기를 바꾼 결과는 아니다.

## 3개 방향

| 안 | 형태의 기준 | 기대 인상 | 검토할 약점 |
| --- | --- | --- | --- |
| A · 다음 칸 | 굵은 ㄴ과 분리된 우상단 조각, 열린 대각 여백 | 정돈되고 한국어 이름과 연결됨 | 자르기/프레임 아이콘으로 읽힐 가능성 |
| B · 열린 n | 소문자 n의 둥근 어깨에 비스듬한 틈 | 제품 브랜드다운 단단함과 작은 특징 | 보통 n 모노그램과 충분히 구별되는지 |
| C · 이름의 이음 | naeil의 ae를 공유 획으로 이어 붙임 | 심벌보다 이름과 글자에 개성 부여 | 독립 아이콘은 ae로 읽히고, 작은 크기의 내부 공간이 제한됨 |

의미는 제작 의도다. 보는 사람이 ‘내일’을 바로 떠올린다는 검증 결과는 아니다.
