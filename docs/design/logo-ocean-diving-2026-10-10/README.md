# naeil — A/B와 스쿠버다이빙 경험의 연결

사용자는 직전 바다 일출 탐색에서 A 또는 B가 괜찮다고 했다. 스쿠버다이빙을 좋아한다는 개인적 배경을 의미에 포함할 수 있는지 검토하되, 맞지 않으면 배제할 수 있도록 요청했다. A/B 중 선택이나 다이빙 요소 채택은 아직 확정되지 않았다.

## 적합성

고요한 물속, 수면에서 들어오는 빛, 올라가는 기포라는 경험은 바다·떠오름·차분함·희망에 연결 가능하다. 마스크·공기통 같은 장비 상징은 다이빙 사업자로 읽힐 가능성이 있어 이번에는 경험에 집중했다. 다이빙 자체가 재시작이라는 뜻을 보편적으로 갖는다고 주장하지 않는다. 사용자에게 중요한 개인적 장면을 브랜드 이야기로 연결하는 제안이다.

## A1 — 올라오는 숨, 떠오르는 해

좋아한 A의 해/물결 구조는 그대로 두고 아래에 서로 다른 크기의 기포 두 개를 넣었다. 수면 아래의 호흡과 위의 일출을 한 장면으로 연결한다. 해와 기포가 올라가는 방향을 공유한다는 발상이며 실제 애니메이션으로 검증하지 않았다.

관찰: 해, 물결, 아래 두 점은 보인다. 수중의 기포로 읽힐 수 있지만 생각 말풍선·장식 점으로도 보일 수 있다. 스쿠버라는 활동을 설명 없이 특정할 수는 없다. 개인적 의미를 은근하게 담는 후속안으로 추천한다. 16px에서는 작은 점이 약해지므로 확정 후 소형 버전에서 한 점만 남기는지 검토해야 한다. 점을 추가하는 것만으로 고유성이 확보됐다는 뜻은 아니다.

## B1 — 물속까지 닿는 아침빛

좋아한 B의 해 아래 세 잔물결 사이를 벌려 아래로 넓어지는 밝은 통로를 만들었다. 수중에서 수면을 바라볼 때의 빛 기둥을 의도했다.

관찰: 밝은 통로보다 잘게 갈라진 물결·생선뼈·탑 같은 인상이 강해졌다. 수중빛이라는 해석은 설명에 의존하고 원안보다 응집력도 떨어졌다. **이번 B1은 추천하지 않는다.** B를 선택한다면 원래 심벌을 유지하고 수중 광선은 사진·배경·브랜드 모션 등 보조 표현에서 탐색하는 편이 낫다. 해당 보조 표현은 아직 제작하지 않았다.

## 현재 추천

다이빙을 심벌 안에 은근하게 담는다면 A1. 로고의 단순함이 더 중요하거나 B가 더 좋다면 기존 A/B를 유지하면서 다이빙 경험은 브랜드 이야기/시각 환경에 반영해도 된다. 이번은 두 파생안의 적합성 비교이며 새로운 독립 콘셉트 두 개라고 세지 않는다. 새 로고나 스킬 확정·수정 없음.

## 도구·검증

logo-icon-design 스킬 적용, 기존 SVG에서 직접 경로 추가/수정. rsvg-convert로 보드와 단색/반전/16·24·32·64px PNG 렌더 후 실제로 열어 비교했다. XML 확인. 사용자 인지 조사, 실사용 제품 적용, 상표 검색 없음. 제품 로고·공유 UI 변경 없음. 색은 이전 임시 팔레트 유지, 워드마크 미정.
