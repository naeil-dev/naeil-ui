# 다국어 공통화 설계 최종 재검토 (sha256 `7a8d1436…b9e7`)

**이 SHA의 설계 검토는 완료됐고, 남은 설계 차단은 없습니다.** 이 판단은 설계 검토에 대한 것입니다. 제품 구현, 배포, 실행 검증은 아직 수행하지 않았고 별도로 진행해야 합니다. 문서 안의 실행 시험 조건은 앞으로 해야 할 검증이며, 설계가 미완성이라는 뜻이 아닙니다.

## 직전 조건 충족 여부 (근거: 문서 열람)

- **RSC 인증 실패:** §6 마지막 문단이 해결했습니다.
  - 401·403이나 cross-origin redirect를 보내지 않고, 보호 데이터 없는 복구 UI를 유효한 RSC payload로 렌더합니다.
  - RSC 헤더를 권한 근거로 쓰지 않습니다.
  - 복구 payload는 private/no-store입니다.
  - document 요청과 RSC 요청을 구분하는 회귀 시험이 있습니다.
- **RSC 실패 시 document 이동:** §7과 §12 업무 상태 행이 해결했습니다.
  - 모든 네트워크 실패에서 store가 보존된다는 주장을 제거했습니다.
  - 공통 `beforeunload`에 Jev를 포함했습니다.
  - 지원 브라우저에서 실패를 주입해 상태 유지 또는 사용자 확인을 검증하고, 확인 없이 유실되면 완료로 보지 않고 전환을 보류합니다.
- **store 재초기화:** §6이 해결했습니다. 같은 사용자·entity·revision이면 재초기화를 금지하고, 새 revision은 충돌 흐름으로 처리하며, 오래된 payload가 store를 되돌리지 못하게 했습니다.
- **standalone 사전 예외:** §7, §9가 해결했습니다. 공통 JSON이 단일 원천이고, 두 번째 수동 원본은 금지했습니다.
- **추가 보완:** root provider에서 번역 hook을 분리했습니다. packed tree에서 next-intl context 중복을 확인하고, 정적 생성과 캐시 결과를 확인하는 항목도 들어갔습니다. 둘 다 제 이전 단정보다 엄격하고 타당합니다.
