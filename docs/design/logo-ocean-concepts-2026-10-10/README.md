# naeil — 바다의 아침, 형상부터 다시

이번 브리프는 ‘해가 바다에서 떠오르는 개념’이다. ㄴ, 영문 n, 기존 배치·프레임을 유지하라는 요청이 아니다. 직전 logo-sea-sunrise 탐색은 사용자의 ‘베이스’를 조형 유지로 과도하게 해석했으며 이번 지시로 철회한다. 의미의 연속성과 형태의 연속성을 구분한다.

[세 러프 비교](board.png) · [SVG 보드](board.svg) · [단색·반전·축소 예비 관찰](proof.png)

## A — 물결을 뚫고

해의 아랫면을 구불거리는 수면이 가린다. 별도 프레임 없이 해와 물 사이의 가는 빈틈이 장면을 만든다. ㄴ의 가로획을 바꾼 것이 아니라 해/수면 두 덩어리의 맞물림에서 다시 만든 형태다.

관찰: 해와 한 줄 물결은 직접적으로 읽히며 세 안 중 일출 장면의 명료함이 가장 높다. 부드러운 흐름과 여유를 기대한다. 한편 일출/바다의 익숙한 도상에 가까워 고유성은 아직 약하고, 물결이 입술·수염처럼 보일 가능성도 있다. ‘떠오름’은 가려진 원에서 의도한 것이며 정지 이미지가 실제 상승 방향을 증명하지 않는다.

## B — 빛이 먼저 닿는 바다

위의 해와 아래로 넓어지는 잔물결 사이의 밝은 틈을 빛의 반사로 해석한다. 바다의 깊이와 멀리서 다가오는 아침을 세로 장면으로 만든다.

관찰: 원/잔물결의 리듬은 보인다. 물 위 반사광은 직접적이지 않고 쌓인 돌이나 탑처럼 보일 수 있다. 조용한 감정은 있으나 의미의 연결과 고유성을 더 해결해야 하므로 이번 추천 순위는 낮다. 색을 바꿔 해결됐다고 주장하지 않는다.

## C — 해를 놓아주는 파도

하나의 굵은 파도가 둥글게 해를 감싸다가 한쪽을 열어준다. 안쪽 원은 해이고, 둘 사이의 빈 공간이 파도의 품과 열림을 만든다. 바다와 따뜻한 보호의 관계를 결합한다.

관찰: 파도/물의 소용돌이와 원은 보이며 하나의 compact한 표식으로 묶이는 힘이 있다. 반면 실제 일출보다 감싸임이 먼저 읽힌다. 해가 파도에 삼켜지는 장면, 문자 C, 눈, 서핑 브랜드로도 보일 수 있다. 문자에서 출발해 그린 것은 아니다. 표식의 형태를 발전시킬 후보로 추천하되 떠오름의 가독성은 A가 우세하다.

## 추천과 단계

A의 장면 명료함과 C의 응집된 표식 구조를 각각 발전 가능한 방향으로 본다. 두 안을 합치거나 하나를 최종안으로 확정하지 않는다. 사용자가 중요하게 보는 ‘떠오름’의 직접성에서는 A, 바다를 품은 간결한 표식에서는 C가 우세하다. 두 가지 모두 제작자 관찰이며 실제 사용자 테스트가 아니다.

세 안 모두 색은 #244B51 / #DE9857 임시 공통 팔레트다. 색 변형을 별개 콘셉트로 세지 않았다. 워드마크·제품 사용처·최종 작은 크기 검증은 방향 선택 뒤에 한다. 예비 단색/반전과16/24/32/64px를 렌더해 확인했으나 축소 이미지의 특징 보존이 브랜드 적합성을 보장하지 않는다. B의 작은 조각과 C의 얇아지는 파도 끝은 후속 정리가 필요하다.

## 실제 실행

logo-icon-design 스킬을 읽고 적용. 새로운 SVG 경로를 직접 작성, rsvg-convert로 PNG 렌더 후 board/proof 이미지를 실제로 열어 확인했다. 원본 assets/a.svg,b.svg,c.svg와 단색/반전 SVG 포함. `python3 docs/design/logo-ocean-concepts-2026-10-10/build.py`로 재현.

이미지 생성 서비스, 외부 레퍼런스/상표 검색은 이번에 실행하지 않았다. 형태의 독창성이나 상표 사용 가능성은 검증하지 않았다. 기존 제품 로고·공유 UI·스킬 파일 수정 없음.
