# 회색 명도로 섬을 표현한 시안

사용자가 능선에 투명한 틈을 내는 단색안을 거절하고 회색 표현을 제안했다. 기존 컬러안의 섬·하늘·해·물결 경로를 그대로 쓰고, 능선의 틈 없이 면의 명도로 구분했다. 두 안은 같은 형태의 표현 방식 비교이며 독립된 로고 콘셉트가 아니다.

- A: 회색 그라데이션. 하늘은 #565656에서 #C8C8C8, 섬은 #454545. 밝은 해와 수면의 반사를 남겼다. 기존 노을의 분위기에 가까워 추천한다.
- B: 단계별 회색 면. 하늘 #B4B4B4, 해 #F5F5F5, 섬 #454545, 물결 #888888 / #626262. 형태는 명확하지만 빛과 깊이감은 줄어든다.

comparison.png에서 컬러 기준안과 밝고 어두운 배경을 비교한다. assets/naeil-gray-gradient.svg와 assets/naeil-gray-flat.svg가 편집 가능한 원본이다. 투명 배경이며 외부 이미지나 글꼴 의존성이 없는 마크다. 비교 보드의 글씨는 배치 확인용이다.

직접 SVG를 제작하고 rsvg-convert로 렌더링했다. 보드와 16/24/32/64/128px proof.png를 실제 열어 확인했다. 16px에서는 작은 해와 섬의 세부 능선이 여전히 약해진다. 어두운 배경에서는 짙은 섬과 외곽의 대비가 줄어든다. 소형과 어두운 배경 전용 최종 보정은 미완료다.

이 결과물은 회색 농도를 사용하는 그레이스케일이다. 검정/흰색 두 값만 허용되는 매체용 단색안은 아니며, 현재 요청에는 그러한 제약이 없다. 이전 시안은 보존했고 제품에는 적용하지 않았다.
