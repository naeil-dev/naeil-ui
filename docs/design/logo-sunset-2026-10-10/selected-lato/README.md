# naeil 로고 — Lato 선택본

사용자의 “2번으로 해도 나쁘진 않을 것 같다”는 선택에 따라 Lato Regular 400 조합을 현재 기준안으로 정리했다. 선택한 노을·섬 심볼, 컬러와 회색 A, 기존의 글자 간격을 유지했다. 이 패키지는 그래픽 원본이며 제품 적용을 뜻하지 않는다.

## 사용할 파일

| 용도 | SVG |
| --- | --- |
| 기본 세로 로고 | `svg/naeil-stacked-color.svg` |
| 웹 헤더 등 가로 로고 | `svg/naeil-horizontal-color.svg` |
| 심볼만 | `svg/naeil-symbol-color.svg` |
| 16–32px 심볼 | `svg/naeil-symbol-color-small.svg` |
| 회색 A | 위 이름의 `color`를 `gray`로 변경 |
| 어두운 배경 | `color-dark` 또는 `gray-dark` 버전 |
| 글자만 | `svg/naeil-wordmark.svg` |

SVG는 글자를 포함해 모두 벡터 경로이며 폰트 설치가 필요 없다. PNG는 투명 배경이다. 심볼 및 세로 조합은 최대 가로 4096px, 가로 조합은 최대 2400px다. `small` 심볼 PNG는 16/24/32/48px다. 화면 미리보기 대신 해당 용도의 원본 파일을 사용한다.

## 배치 기준

- 가로·세로 비율을 유지하고 색과 글자 간격을 임의로 바꾸지 않는다.
- 로고 바깥에는 적어도 심볼 속 해의 지름 정도 여백을 권장한다. 이는 적용 시 확인할 초기 기준이다.
- 16–32px에서는 글자 없는 `small` 심볼을 사용한다. 작은 크기에서 섬의 세부 능선과 색의 미묘한 차이는 줄어든다.
- 회색 버전은 명도를 사용하므로 검정/흰색 두 값만 허용하는 스탬프용 데이터가 아니다.
- 어두운 배경 버전은 `#252525`에서 확인했다. 사진 위 배치와 다른 배경색은 실제 화면에서 확인한다.

## 라이선스

Lato는 SIL Open Font License 1.1이며 상업용 로고 그래픽 제작이 허용된다. 저작권자는 tyPoland Lukasz Dziedzic이며 Reserved Font Name은 Lato다. `licenses/Lato-OFL.txt`에 원문, `licenses/sources.json`에 원본 폰트와 라이선스의 정확한 출처 및 해시를 보관했다. 이 패키지에는 폰트 파일을 배포하지 않는다. 글자 경로로 만든 로고는 폰트를 설치하지 않아도 표시된다.

## 확인한 내용과 남은 적용 작업

선택본 미리보기에서 컬러·회색·밝고 어두운 배경을 열어 확인했다. 기존 크기별 렌더와 헤더 샘플 검토는 `evidence/`에 보관했다. `verification.json`에 SVG 의존성·참조, PNG 크기·투명도·클리핑 검사 결과를 기록한다.

실제 웹사이트나 앱에 교체 적용하거나 배포하지 않았다. 실제 사용처의 배치 및 인쇄 교정은 해당 작업 시 확인한다. 이전 후보는 비교용으로 보존했다. 외부 서비스 없이 기존 벡터를 모으고 rsvg-convert로 직접 렌더링했다.
