# naeil — 정밀 조정 및 고해상도 원본

사용자가 선택한 섬이 있는 컬러안과 회색 그라데이션 A를 기준으로 마감 품질을 높였다. 원래 시안과 제품 파일은 보존했다.

## 변경 내용

- 물결의 끝과 왼쪽 단면을 둥글게 연결하고 두 물결의 곡선 흐름을 정돈했다.
- 섬 능선의 급한 꺾임과 하늘 외곽의 접합을 부드럽게 다듬었다.
- 컬러 수평선의 급한 붉은 띠를 완화하고 물결의 반사광 위치를 정리했다. 회색 A의 명도 구성을 유지했다.
- 투명한 정사각 캔버스에서 마크가 차지하는 폭을 약 69%에서 85%로 높였다. 동일 크기의 아이콘에서 더 잘 보이게 하기 위한 조정이다.
- 16–32px용은 해의 반지름을 12에서 16으로 키우고, 섬 능선을 단순화하고, 물결 간격과 두께를 보정했다. 고해상도 원본을 단순 축소한 파일과 구분한다.
- 어두운 배경용은 섬과 푸른 물결의 명도를 올려 외곽이 배경에 묻히는 현상을 줄였다.

## 파일 선택

| 용도 | 파일 |
| --- | --- |
| 밝은 배경의 컬러 마크 | `assets/naeil-color.svg` |
| 밝은 배경의 회색 A | `assets/naeil-gray.svg` |
| 어두운 배경 | `assets/naeil-color-dark.svg`, `assets/naeil-gray-dark.svg` |
| 16–32px 아이콘 | 위 이름에 `-small`이 붙은 SVG 또는 해당 크기의 PNG |
| 마크 + naeil 세로 조합 | 위 이름에 `-lockup`이 붙은 SVG 또는 PNG |

일반 마크 PNG는 64/128/512/1024/2048/4096px 정사각이며 모두 투명 배경이다. 조합 PNG는 가로 1024/2048/4096px, 세로는 각각 800/1600/3200px다. 작은 크기용은 16/24/32/48px를 제공한다. 48px는 일반 SVG와 작은 크기용을 사용 환경에서 비교할 수 있는 중간 크기다. SVG는 해상도 독립 원본이다. PNG 역시 작은 이미지를 확대하지 않고 SVG에서 각 크기로 직접 렌더링했다.

SVG 원본에는 외부 이미지나 폰트 참조가 없다. 조합의 글자는 시스템 Arial Regular를 fontTools로 경로 변환해 서체 대체에 따른 변화를 막았다. Arial 폰트 파일은 배포하지 않는다. 해당 글자는 배치용 서체를 안정적으로 출력한 것이며, 새로 디자인하거나 확정한 전용 워드마크는 아니다. 이전 미리보기의 시스템 서체 대체 결과와는 미세한 차이가 있을 수 있다.

## 확인 결과

`preview.png`에서 컬러·회색·밝고 어두운 배경을 확인했다. `evidence/before-after.png`는 동일 배율의 전후 비교다. `evidence/size-proof.png`에는 실제 16/24/32/64px PNG와 헤더 배치를 넣었다. `evidence/pixel-proof.png`는 실제 래스터의 최근접 확대이며, 왼쪽부터 16px 일반/보정, 32px 일반/보정이고 위는 컬러, 아래는 회색이다.

작은 크기 보정 후 해가 더 크게 남고 두 물결의 분리가 개선됐다. 16px에서는 세부 능선과 그라데이션의 미묘한 차이까지 유지되지는 않는다. 32px 이상에서는 섬과 해를 더 분명히 볼 수 있다. 어두운 배경용은 `#252525`에서 확인했으며 모든 배경에 대한 일괄 보증은 아니다. 회색안은 회색 농도를 사용하는 버전으로, 두 값만 허용하는 스탬프나 각인용 단색 버전이 아니다. 인쇄 교정은 수행하지 않았다.

`verification.json`은 SVG 참조, 외부 의존성, PNG 크기·투명도·클리핑, 회색 출력의 RGB 일치 검사 결과다. 이 구조적 검사는 위의 실제 시각 확인을 보조한다.

## 제작 기록

`logo-icon-design` 기준으로 네이티브 SVG 경로를 직접 편집했다. Python / fontTools / rsvg-convert / Pillow로 경로 변환, 렌더링, 픽셀 검사를 수행했다. 외부 디자인 서비스나 이미지 생성 도구를 사용하지 않았다. 빌드를 다시 실행하려면 `build.py`, Python의 Pillow와 fontTools, `rsvg-convert`, 시스템 Arial.ttf가 필요하다. 전후 비교 시트만 이전 시안 파일을 읽는다. 앱·웹사이트의 로고 교체 및 배포는 수행하지 않았다.
