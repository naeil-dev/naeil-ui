# naeil — 노을의 온기

사용자가 설명한 사진의 감정: 그라데이션의 따뜻함, 자연에 대한 경외감, 하루를 잘 마쳤다는 안도감. 브랜드와의 연결은 “오늘을 잘 마치고, 편안하게 맞는 내일”이다. 기존 ㄴ 형태나 다이빙 기호를 요구사항으로 삼지 않았다.

## 비교 시안

- `board.png` / `board.svg`: 컬러, 어두운 배경, 단색 비교.
- **01 하루를 담은 노을** (`assets/a-color.svg`): 넓은 하늘 안의 작은 해와 수면에 이어지는 금빛. 사진의 공간감과 감정에 더 가까워 우선 추천한다. 큰 반원 자체를 해로 오독하거나 풍경 엠블럼으로 볼 수 있다.
- **02 수면에 남은 온기** (`assets/b-color.svg`): 낮은 해와 두 겹의 잔잔한 물결. 해와 바다가 더 직접적으로 읽히지만, 익숙한 해변·여행 브랜드 모티프에 가까울 수 있다.

두 안은 하늘 속 작은 해와 독립된 큰 해라는 차이가 있지만 모두 노을과 수면이라는 같은 계열이다. 완전히 다른 상징 체계를 비교한 탐색은 아니다. 의미와 감정은 디자인 의도이며 사용자 검증 결과가 아니다.

## 색과 제작

사진의 색을 참고해 깊은 하늘 `#284972`, 푸른 여운 `#617579`, 저녁 안개 `#9B7755`, 금빛 `#E5A348`, 노을 `#DA702B`, 남은 온기 `#B94628`로 조정했다. 해안선이나 사진을 그대로 추적하지 않았다. 어두운 배경에서는 푸른 물결이 묻히는 문제를 보고 별도의 밝은 색상 버전을 만들었다.

`logo-icon-design`과 `imagegen` 스킬을 읽었다. 참조 사진을 사용한 이미지 생성 도구 호출은 HTTP 405 Method Not Allowed로 실패했다. 결과물은 이미지 생성 서비스의 출력이 아니라 `build.py`로 직접 작성한 SVG이며, `rsvg-convert`로 PNG를 렌더링했다. 외부 로고 제작 서비스는 실행하지 않았다.

## 예비 확인과 남은 작업

SVG XML 파싱, 비교 보드, 밝고 어두운 배경, 단색·반전, 16/24/32/64px 렌더를 확인했다. `proof.png`는 크기별 비교, `pixels.png`는 실제 16px 래스터 확대다. 16px에서는 01의 작은 해와 색의 미묘한 차이가 약해진다. 최종 소형 전용 형태의 검증은 남아 있다.

워드마크는 배치 확인용 시스템 서체이며 최종 레터링이 아니다. 고유성이나 상표 유사성은 검증하지 않았다. 실제 제품 로고, 공유 UI 토큰, 배포에는 변경이 없다. 방향 선택 후 형태·색·워드마크와 실제 사용처를 다듬을 탐색 시안이다.
