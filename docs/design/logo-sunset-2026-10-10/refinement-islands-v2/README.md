# 섬의 존재감을 높인 조정안

사용자의 “좀 더 섬이 보여도 될 것 같다”는 요청에 따라 양쪽 섬의 높이와 능선을 키웠다. 왼쪽은 길게 낮아지는 지형, 오른쪽은 짧고 높은 지형으로 비대칭을 유지하고 해 주변 공간을 열어 두었다. 색, 해, 물결은 직전 안과 같다.

- preview.png: 새 시안 (2배 해상도)
- comparison.png: 직전의 낮은 섬과 이번 안 비교
- assets/naeil-islands-color.svg: 편집 가능한 컬러 원본
- proof.png: 배경 및 크기별 예비 렌더

직접 SVG 경로를 수정하고 rsvg-convert로 렌더링했다. 이전 파일은 보존했다. 단색에서는 섬이 하늘에 합쳐지며, 작은 크기 전용 단순화는 미완료다. 서체는 배치 확인용이고 제품 적용은 하지 않았다.
