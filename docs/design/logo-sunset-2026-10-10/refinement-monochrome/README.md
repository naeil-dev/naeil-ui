# 섬이 남는 단색 로고

섬을 하늘에 합치던 이전 단색 처리 대신 능선에 투명한 틈을 냈다. 검정과 흰색 원본은 각각 단일 잉크이며 회색 음영을 사용하지 않는다. SVG luminance mask로 해와 능선을 뚫어 배경색에 관계없이 투명하게 동작한다. 컬러 형태는 v2와 같다.

- comparison.png: 컬러·검정·흰색 비교
- assets/naeil-islands-mono.svg: 검정 원본
- assets/naeil-islands-reverse.svg: 흰색 원본
- proof.png: 실제 16/24/32/64/128px 렌더 비교

직접 SVG를 작성하고 rsvg-convert로 출력했다. 비교 이미지와 크기별 렌더를 열어 확인했다. 64px 이상에서는 능선과 섬이 구분되며, 16/24px에서는 능선 틈이 픽셀보다 좁아 지형의 판독이 약하다. 소형 전용 형태는 별도 조정이 필요하다. 인쇄용 납품 시에는 마스크를 불리언 경로로 변환하고 출력 조건에 맞는 최소 간격을 검증해야 한다. 워드마크는 배치 확인용이다. 제품 적용은 하지 않았다.
