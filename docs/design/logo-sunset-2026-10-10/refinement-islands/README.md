# 1번 후속 조정 — 낮은 섬과 부드러운 외곽

사용자가 1번을 선호하고 섬 등의 지형을 살짝 추가하자고 제안했다. 넓은 노을, 작은 해, 차분한 바다는 유지한다. 사진의 해안선을 그대로 추적하지 않고 양옆에 비대칭의 낮은 지형을 직접 그렸다. 기존 결과물은 보존했다.

- `preview.png`: 조정한 컬러 시안, 1600×1440.
- `comparison.png`: 이전 러프와 조정안, 2880×2040.
- `assets/naeil-islands-color.svg`: 독립적인 편집 가능 SVG 마크.
- `assets/naeil-islands-dark.svg`: 어두운 배경용 색.
- `assets/naeil-islands-mono.svg`, `assets/naeil-islands-reverse.svg`: 단색 단순화. 섬은 하늘과 합쳐지며 별도로 남지 않는다.
- `assets/naeil-smooth-no-islands.svg`: 외곽만 다듬은 비교용 마크.
- `proof.png`: 배경·단색·16/24/32/64px 예비 렌더.

이전 물결의 날카로운 끝, 직선으로 닫힌 왼쪽 단면, 하늘 아랫부분의 급한 접합은 경로 자체의 특징이었다. 단순한 저해상도 문제로 설명할 수 없다. 이번에는 곡선 끝과 접합을 수정하고 2배 해상도로 비교 이미지를 출력했다. 화면 미리보기의 축소 보간에 따른 거칠기는 남을 수 있으므로 원본 SVG도 제공한다.

직접 작성한 SVG와 rsvg-convert만 사용했다. 비교 보드와 예비 크기별 렌더를 실제 열어 확인했다. 컬러에서 섬은 하늘과 수면의 깊이를 더하지만, 아주 작게 쓰면 지형과 작은 해가 희미해진다. 16px 전용 형태는 아직 만들지 않았다. 대형 컬러 시안에서의 인상이 작은 크기에서도 그대로 유지된다는 의미는 아니다.

색과 워드마크는 최종 확정 전이며 서체는 배치 확인용이다. 제품 파일이나 공유 UI는 변경하지 않았다.
