# naeil — 해·떠오름·바다

사용자의 최신 지시: 이전의 새로운 상징 후보들은 모두 맞지 않는다. 현재 ㄴ+일출 로고를 베이스로 다시 생각하고, ‘해’·‘뜬다’·바다 느낌을 담는다. 기존 로고 구조를 출발점으로 삼는 새 러프이며 최종 방향 확정은 아니다.

[세 방향 비교](board.png) · [편집 가능한 보드](board.svg) · [예비 형태 확인](proof.png)

## A — 수면에서 막 떠오른 해

현재 ㄴ의 곧은 수평선을 유지하고 해를 더 드러낸다. 수평선 아래 짧은 잔물결을 두어 바다를 암시한다. 기존 표식의 연속성과 고요함이 장점. 다만 아래 획이 물보다 밑줄처럼 보일 수 있어 바다와 움직임은 약하다.

## B — 물결 사이로 떠오르는 해 · 우선 추천

ㄴ의 가로획 자체를 하나의 낮은 파도로 바꾼다. 해의 아랫부분과 수면 사이에 띠 모양의 틈을 남겨 해가 물결 뒤에 있는 장면을 만든다. 추가 바다 아이콘을 붙이지 않고 두 요소의 관계로 장면을 만든 점이 장점이다. 파도가 너무 높으면 산이나 언덕으로 보일 수 있으므로 낮게 유지했다. 곡률과 가림의 정도는 이후 다듬을 대상이다.

## C — 바다에 길을 내는 해

해 아래 반사광이 가까워질수록 넓어지는 두 조각으로 보이게 하고, 수평선도 그 빛길을 위해 열린다. 희망이 나에게까지 닿는 느낌, 바다의 깊이가 장점. 반사광은 도로·활주로처럼 보일 수 있고 작은 크기에서는 조각이 복잡해진다.

## 관찰과 미정 사항

- 세 후보는 서로 다른 로고 세계관이 아니라 사용자가 지정한 기존 구조 안에서 수면·파도·반사광을 다르게 다룬 세 방향이다.
- 모든 후보에서 해와 아래쪽 선의 관계는 보인다. B는 수면의 굴곡이 가장 직접적이고, A는 가장 정적, C는 장면은 풍부하지만 요소가 많다. 제작자 시각 관찰이며 사용자 인지 시험은 아니다.
- 정지한 해/수면만으로 실제 상승 방향과 일출·일몰을 완전히 구별할 수는 없다. ‘naeil’이라는 이름이 아침의 해석을 돕는다. 화살표나 속도선을 붙여 차분함을 해치지는 않았다.
- 임시 색: 바다 #254D55, 해 #DF9954. 따뜻함·바다 감정 확인용이며 확정 팔레트나 shared UI 토큰 변경 아님. 단색에서도 비교했다.
- 보드의 naeil은 시스템 폰트로 넣은 배치용 표기. 워드마크 디자인 미정.
- 16/24/32/64px와 단색/반전 렌더를 실제로 열어 예비 관찰했다. 16px에서는 A의 잔물결과 C의 반사광 세부가 약해져 최종 크기 검증을 통과했다고 주장하지 않는다. B의 수면 굴곡은 비교적 남는다. 제품 사용처·소형 전용 기하·정식 워드마크는 선택 이후 검증할 대상이다.

## 사용 도구와 파일

현재 src/components/logo.tsx와 이전 로고 SVG, 기존 탐색 기록을 읽었다. logo-icon-design 스킬 적용. 원본 SVG 직접 작성, rsvg-convert로 PNG 생성 후 이미지 직접 관찰. 기존 로고는 비교용으로 복제했으며 보드에서 fill=none을 유지해 원래 열린 ㄴ을 재현했다. 이미지 생성 서비스·외부 검색·상표 검색은 이번에 사용하지 않았다. 제품 Logo 컴포넌트나 스킬 원문 변경 없음.

assets/a.svg, b.svg, c.svg 및 각 -mono/-reversed.svg에 편집 가능한 경로가 있다. 재현: 저장소 루트에서 `python3 docs/design/logo-sea-sunrise-2026-10-10/build.py`.
