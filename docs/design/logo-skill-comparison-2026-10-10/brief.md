# 공통 입력 — naeil / 스킬 비교 실험

사용자가 이미 확정한 브리프로 외부 스킬들을 실제 적용하고 결과를 비교한다. 새 스킬 개발, 생산 자산 교체, 방향 확정은 하지 않는다. 선택 전 콘셉트 탐색이다.

- 이름: 소문자 naeil, 한국어 ‘내일’.
- 제품 브랜드. 구체적인 업종과 대상은 미정; 디지털 제품군에 쓰일 수 있는 브랜드 심벌로 가정한다. 특정 기능을 invent하지 않는다.
- 감정: 차분함, 따뜻함, 희망, 다시 시작할 수 있다는 안도감. 차분하되 기억에 남을 고유한 형태.
- ‘내일’을 장면·경험·관계로 새롭게 해석한다. 설명을 들으면 공감하고, 실제 형태에서도 연결이 어느 정도 느껴져야 한다.
- 기존 ㄴ+해의 가치는 의미와 장면. ㄴ, 해, 일출을 유지할 필요 없음. n/ae의 기교나 무의미한 추상 도형으로 대신하지 않는다.
- 기존 후보는 모두 거절됨: 이불 걷기, 매듭 실, 책장 넘기기, 징검돌, 빈 벤치. 이 다섯 스케치의 미세변형을 재제안하지 않는다. 이 장면 전부를 영구금지한다는 뜻은 아니지만 이번에는 새로 탐색한다.
- 색상·폰트·구성 미정. 심벌 중심, 워드마크는 중립적 위치 확인만. 브랜드 보드의 색/서체는 임시 탐색으로 명시.
- 평가는 의미의 연결, 예상 감정, 고유한 형상, 다른 해석 가능성, 다음에 개선할 점. 설명 없는 형태와 함께 본다.
- 사용자가 방향을 선택한 다음 색·워드마크·세밀한 형태·소형 실사용 검증으로 넘어간다. 스킬이 요구하는 소형 시트는 예비 관찰만 가능, 최종 통과로 주장하지 않는다.
- 공식 후보로 만드는 수: Kaan3, Neon3. Brandkit은 원래 산출 방식(하나의 브랜드 개요 이미지)을 유지한다. 단일 실행이고 생성 매체/산출 수가 달라 인과적인 스킬 성능 비교가 아님.
