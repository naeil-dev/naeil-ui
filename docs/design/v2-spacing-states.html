간격과 상태까지 일관되게

글씨는 그대로, 간격과 상태 표현을 비교합니다. 각 예시는 독립적으로 조작할 수 있습니다.

간격 추천 기본은 여유 있게, 정보가 많은 화면만 촘촘하게. 두 모드 모두 본문 16px를 유지합니다.

기본 · 입력·버튼 40px / 목록 행 최소 72px

짧은 전환 · 색 변화 120ms / 팝업·알림 180ms. OS의 움직임 줄이기 설정을 우선합니다.

언어 메뉴, 새 작업 팝업, 설정 저장을 눌러 보세요. 아래에서는 목록의 로딩·빈 화면·오류도 비교할 수 있습니다.
